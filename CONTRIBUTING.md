# Contributing

Thank you for helping improve Radial Vocab Video Studio.

1. Open an issue for substantial behavior or interface changes before implementation.
2. Create a focused branch and keep unrelated formatting changes out of the patch.
3. Run `pnpm typecheck`, `pnpm test`, and `pnpm build` before opening a pull request.
4. Add or update tests when behavior changes.
5. Do not commit API keys, `.env`, uploaded media, generated videos, or machine-specific paths.

By contributing, you agree that your contribution is licensed under the MIT License.
